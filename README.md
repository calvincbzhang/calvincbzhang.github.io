# calvincbzhang.github.io

Personal website for Chen Bo Calvin Zhang, built with Jekyll and the al-folio theme.

## Local development

Install the Ruby dependencies, then run:

```sh
bundle exec jekyll serve
```

## Content

- Homepage copy lives in `_pages/about.md`.
- News items live in `_news/`.
- Publications are managed in `_bibliography/papers.bib`.
- Site-wide settings live in `_config.yml`.

## Deployment

The site deploys through the GitHub Actions workflow in `.github/workflows/deploy.yml`.
